# Clockless Weather / Static Sermon

> The clocks are not broken. They have retired.

The first prediction arrived at 09:11 and said "sunny after noon."
At 09:12 it said "low humidity with uncertain thunder."
At 09:13 it said nothing, only a clean, patient hiss.

In this district, weather has stopped paying attention to hands on a dial.
The sky now keeps appointments in pulses:

- A cold gust for the confession.
- A warm drift for the absolution.
- A brief silence for the sermon.

When the static starts speaking, we used to blame reception.
Then we noticed it was never the weather report speaking at all.
The report was the church, and the static was the choir.

I now carry rain gear and a notepad.
The notepad has no timestamps, only margins.
Every line ends with the same annotation:

> It was both this and not this, and therefore true enough for the hour without a clock.
